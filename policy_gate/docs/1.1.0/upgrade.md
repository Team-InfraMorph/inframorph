# 업그레이드 안내

## legacy에서 1.0.0

기존 판정은 보존합니다. 운영 배포의 보존된 입력과 이미지 식별값을 확보할 수 있으면 자동 재검사하고 배포별 운영자 검토를 요구합니다. 자료가 없으면 재검사 불가로 표시합니다.

## 여러 버전 건너뛰기

현재 정책부터 목표 정책까지의 변경 명세를 누적합니다. 중간 필수 조치를 생략하지 않습니다. 명세가 없거나 적용 여부를 모르면 확인 필요입니다.

## 재검사·검토·재배포

재검사는 모델 호출·빌드·배포 없이 보존 입력을 검사합니다. 검토는 특정 검사 실행과 정책에 연결되며 위반을 면제하지 않습니다. 메이저 전환은 전체 필수 검사와 배포별 검토가 필요합니다.

결과물 변경이 필요 없으면 재배포하지 않습니다. 필요한 경우 동일 commit으로 새 배포를 만듭니다. 소스 수정이 필요하면 새 commit의 일반 배포를 수행합니다. 기존 서비스는 자동 중단하지 않습니다.

## 체험 보드 지원 {#board-transition}

V3 체험 보드의 Local 프로필을 추가합니다. 이 지원 추가 자체는 기존 배포의 재검사나 재배포를 요구하지 않습니다. 1.0.0에서 전환할 때는 1.1.0의 기존 자동 복구 변경에 따른 검토·재검사 조치를 함께 적용합니다. [추가 지원 계약](board.md#scope)을 확인하세요.
