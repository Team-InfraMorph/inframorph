# 정책 1.1.0 릴리스 노트

## 추가된 지원 {#changes}

G-002 revision 2: 정확히 등록된 체험 V1·V2 commit과 UI·이미지를 포함한 전체 파일 묶음을 허용합니다. 화면 자료는 실행 요구 근거로 인정하지 않습니다.

G-003 revision 2: 체험 보드는 Local만 지원합니다. 기존 샘플의 Local/AWS 지원은 유지합니다.

## 이전 동작과 새 동작 {#behavior}

1.0.0에서는 새 서버 및 src/web 파일이 검토 목록에 없어 거부됐습니다. 1.1.0에서는 두 검토된 묶음만 허용합니다. 임의 웹 파일, 변조된 그림, 서로 다른 버전의 파일 혼합은 여전히 거부합니다.

## 배포 영향 {#impact}

기존 샘플에 대한 새로운 차단 조건은 없습니다. 이 지원 추가만으로 기존 배포를 재검사·재배포하지 않습니다. 새 체험 배포는 활성 1.1.0으로 전체 검사합니다. 기존 정책·판정은 바꾸지 않습니다.

## 검증 {#validation}

[체험 보드 계약](board.md#scope)과 tests/test_demo_board.py에서 정상·위반·Local 제한·worker 실행 검증을 확인합니다. 실제 AI·Docker·공개 접속·휴대폰 확인은 별도 실행 안내에 기록합니다.
