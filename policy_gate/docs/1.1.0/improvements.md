# 확인된 한계와 후속 정책 보완안

## 분류 기준 {#priorities}

이 페이지는 현재 제공 기능이 아니라 보완 계획입니다. 이번 문서 작업에서는 규칙을 변경하지 않습니다. 아래 관찰은 전체 실행 경로 우회 성공 주장과 구분합니다.

- 우선 해결: 현재 지원 경로에서 재현된 잘못된 통과·실행 허용. 이번 사례 검증으로 그러한 전체 경로 우회를 확인했다고 주장하지 않습니다.
- 다음 보완: 지원 범위 내 판정 설명·분류·근거·검증 부족.
- 범위 확장 시 검토: 현재 미지원인 앱·언어·변환을 지원할 때 필요한 검사.

## 오류 분류 검토 {#classification}

예외 문자열의 unsupported/unavailable 포함 여부만으로 운영 의미가 항상 명확하지는 않습니다. 향후 코드별 분류를 바꾼다면 이전·새 판정과 재검사 영향을 검토해야 합니다. 설명을 고치는 것과 판정을 바꾸는 것은 다른 작업입니다.

## 보완 항목을 완료하는 조건 {#acceptance}

문제 상황·지원 경로·최소 재현 → 현재 방어와 미탐/오탐 여부 확인 → 제안 조건 → 정상·위반·경계·오류 테스트 → 판정 변경과 버전 영향 검토 → 새 검사로 해결 확인 순서입니다. 재현하지 못한 가설을 확정 결함이나 완료 항목으로 바꾸지 않습니다.
