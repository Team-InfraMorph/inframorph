# 정책 1.1.0 안내

## 이 정책으로 판단하는 것 {#contract}

InfraMorph는 AI가 읽은 앱 요구를 배포 설계와 코드 변환으로 연결합니다. Policy Gate는 그 사이에서 지원 소스, 분석 근거, 설계 관계, 패치 무결성과 허용 변환, 최종 빌드 입력을 검사합니다. 현재는 **검토된 demo-app Node 22 프로필의 정책**이며 범용 앱 안전성 판정기가 아닙니다.

현재 정책 버전은 1.1.0입니다. 정책 규칙과 문서를 같은 버전으로 확인합니다. 설명의 수정 이력은 Git에서 관리합니다. legacy 2.2.0은 별도의 과거 기록이며 숫자로 크기를 비교하지 않습니다.

## 통과를 읽는 기준 {#meaning}

규칙 PASS는 해당 조건을 만족했다는 뜻입니다. 적용 제외는 검사 수행과 다르고, 선행 실패로 수행하지 않은 규칙도 통과가 아닙니다. 전체 필수 검사 완료, 이미지 빌드, 서비스 실행, 공개 접속 성공은 서로 다른 결과입니다.

문서가 자세하다고 관찰 근거가 늘어나는 것은 아닙니다. 결과에 없는 파일·줄·원인을 설명에서 복원한 것처럼 제시하지 않습니다. [결과와 오류 구분](results.md#classification)을 확인하세요.
