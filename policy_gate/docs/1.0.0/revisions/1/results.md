# 검사 결과 읽기

## 판정

PASS는 해당 검사 실행의 필수 규칙이 모두 충족되었다는 뜻입니다. BLOCK은 위반, UNSUPPORTED는 지원 범위 밖, ERROR는 확인 실패입니다. NOT_RUN은 선행 실패 등으로 미실행, NOT_APPLICABLE은 명시된 적용 조건에 해당하지 않음을 뜻합니다.

## 검사 시점과 규칙

빌드 직전이라는 시점과 P-001이라는 규칙을 구분합니다. 같은 규칙을 재실행하면 별도의 실행 ID가 생깁니다. 동일 실행의 중복 전달만 제거합니다.

## 과거 기록

legacy 기록은 단계별 요약입니다. 세부 규칙의 수행 여부·시각·구현 해시는 없는 정보를 추정하지 않습니다.

## 입력 식별

소스 commit, 소스·설계·패치 해시, 배포 이미지 식별값을 연결합니다. 정책 변경이나 입력 변경 후에는 이전 검토를 그대로 실행 승인으로 사용하지 않습니다.
