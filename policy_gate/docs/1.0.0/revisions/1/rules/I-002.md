# I-002 · worker 실행 근거

## 목적과 검사

worker 명령·파일·근거와 요구 누락을 확인합니다.

## 적용 조건

단계 intent · reviewed-node22 · rule('I-002')

## 정상 사례

node src/worker.js 명령, 존재하는 파일과 진입 파일 또는 package script 근거를 제공합니다.

## 위반·미지원 사례

파일 누락, 무관한 근거 또는 실제 worker 요구 누락을 차단합니다. 지원하지 않는 실행 명령은 미지원입니다.

## 수정 방법

지원하는 worker 진입 파일과 실행 명령을 확인하세요.

## 한계

worker가 없더라도 소스에 worker가 숨겨져 있지 않은지 누락 검사를 수행합니다.

## 이력과 검증

도입 1.0.0 개발 중 · 규칙 revision 1

구현: policy_gate/gate.py + policy_gate/rules.py

회귀 테스트: tests/test_policy_lifecycle.py, tests/test_e_runtime.py, tests/test_policy_hardening.py

직접 사유 코드: package_invalid, worker_command_unsupported, worker_entry_missing, worker_evidence_unrelated, worker_requirement_missing

공유 스키마·파일·파서 검사의 오류도 전파됩니다. 미실행은 upstream_not_completed로 기록합니다.
