# I-003 · DB 종류와 근거 일치

## 목적과 검사

DB 종류·요구 누락·datasource 근거를 확인합니다.

## 적용 조건

단계 intent · reviewed-node22 · rule('I-003')

## 정상 사례

Prisma datasource가 sqlite면 Intent도 sqlite이고 근거가 datasource 구간을 가리킵니다.

## 위반·미지원 사례

sqlite 소스를 postgresql로 주장하거나 DB 요구 자체를 생략하면 차단합니다.

## 수정 방법

Prisma datasource에 맞게 DB 요구와 근거를 수정하세요.

## 한계

Prisma의 지원 구문 범위 안에서 provider와 근거를 대조합니다. 실제 DB 접속은 하지 않습니다.
