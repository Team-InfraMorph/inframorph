# I-004 · 파일 저장 근거

## 목적과 검사

검토된 저장 코드의 읽기·쓰기와 근거가 연결되어야 합니다.

## 적용 조건

단계 intent · reviewed-node22 · rule('I-004', applies=any((s.kind == 'persistent_files' for s in intent.state)), reason='no_persistent_files')

## 정상 사례

검토된 src/images.js의 readFile/writeFile과 겹치는 근거 줄 및 uploads 경로를 전달합니다.

## 위반·미지원 사례

저장과 무관한 줄은 차단합니다. 다른 저장 구현이나 경로는 미지원입니다.

## 수정 방법
