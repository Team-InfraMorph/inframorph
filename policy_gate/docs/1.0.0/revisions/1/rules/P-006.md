# P-006 · JavaScript 실행 구문

## 목적과 검사

지원 구문으로 파싱하고 금지 실행 구문을 확인합니다.

## 적용 조건

단계 patch · reviewed-node22 · rule('P-006')

## 정상 사례

지원 JS를 파싱합니다. 주석이나 문자열 속 eval은 실행 구문으로 오인하지 않습니다.

## 위반·미지원 사례

실행 가능한 eval 또는 child_process 구문은 차단합니다. 파서 장애는 ERROR입니다.

## 수정 방법

금지된 실행 구문을 제거하거나 지원 구문을 사용하세요.

## 한계

정적 AST 규칙은 모든 우회 가능한 프로그램을 증명하지 못합니다. 검토된 소스 제한과 함께 사용합니다.
