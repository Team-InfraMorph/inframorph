# 정책 1.0.0 소개

## 정식 관리의 시작

현재 버전은 **1.0.0 개발 중**입니다. 출시 태그·PR은 아직 없습니다. 검토된 demo-app Node 22 소스와 Local/AWS 배포 설계를 대상으로 합니다.

기존 legacy 2.2.0 기록은 별도의 과거 기록입니다. 2.2.0보다 작은 숫자라는 이유로 다운그레이드로 비교하지 않습니다. 과거 기록을 새 규칙 통과로 바꾸지 않습니다.

## 무엇을 보장하나요

지원하는 소스·분석·설계·패치의 검사 조건을 확인합니다. 검사 통과와 Docker 빌드 성공, 실제 배포, 공개 접속 성공은 별개의 결과입니다.

## 무엇을 보장하지 않나요

임의 웹 앱의 전체 안전성, 모든 비밀정보 탐지, 운영 환경의 지속적 변경 탐지, 모든 취약점 탐지를 보장하지 않습니다. 저장된 이미지 식별값은 배포 당시 연결을 설명하며 현재 실행 환경의 drift를 새로 관측한 값이 아닙니다.

## 이용 순서

배포 화면에서 검사 요약을 확인하고, 규칙을 펼쳐 근거를 확인하세요. 버전 비교에서는 필요한 조치를, 배포 영향에서는 운영 중인 배포별 상태를 확인합니다.
