# 문서와 정책 변경 이력

## 문서 revision 2 {#revision-2}

정책 inframorph-policy/1.0.0, 규칙 revision 1을 유지합니다. 이번 변경은 문서 보완이며 정책 판정·지원 범위·규칙 실행 코드를 바꾸지 않습니다.

| 구분 | 이전 설명 | 보완 설명 | 운영 영향 |
|---|---|---|---|
| 상세화 | 목적·짧은 사례·테스트 파일 나열 | 입력·실행 순서·사유·근거·조치·재검증 | 문서 열람만으로 재검사/재배포 요구 없음 |
| 설명 정정 | 저장 읽기·쓰기 연결을 넓게 표현 | 지원 호출 중 하나와의 관련성 및 G-002 누락 방어 구분 | 판정 변화 없음 |
| 설명 정정 | 적용 제외의 부수 검사 설명 부족 | P-004의 템플릿 파싱과 장애 가능성 명시 | 판정 변화 없음 |
| 설명 정정 | 공통 오류를 포괄적으로 안내 | unreadable_source BLOCK과 파서 ERROR 구분 | 판정 변화 없음 |
| 연결 보완 | 테스트 파일의 존재 중심 | 사례와 정확한 메서드·실행 검증 연결 | 기존 테스트 의미는 확대 해석 안 함 |
| 제안 | 한계 나열 | 근거·재현 여부·우선순위·완료 조건 | 아직 미구현, 실행 허용 변경 없음 |

문서 revision 1은 그대로 보존합니다. 검사 기록의 당시 문서 링크는 revision 1을 유지하고 새 검사부터 현재 설명 revision을 기록합니다. 문서 내용 해시는 바뀌지만 정책·규칙·구현 해시는 같아야 합니다.

## 1.0.0 {#policy-baseline}

정식 규칙별 기록과 버전·검사·배포 영향 관리의 첫 기준선입니다. 출시 태그·PR은 아직 없습니다. 존재하지 않는 과거 1.x 릴리스를 만들지 않습니다.

## legacy 2.2.0 {#legacy}

관리 체계 도입 전 단계별 요약입니다. 정식 1.0.0의 이전 SemVer 릴리스가 아니며 새 규칙 결과로 재표기하지 않습니다.
